Required File Structure

File Rules:

  • File must be a .csv format.
  • Required columns:
    subject_id • session_id • trial_id • category • time_index • channel_1...
  • Optional columns:
    labels  (one label per trial — if included, must be consistent)
  • category must be 'motor' or 'imagery'.
  • trial_id must be whole integers — no decimals (e.g. 1, not 1.0).
  • Every trial must have the same number of rows (consistent time points).
